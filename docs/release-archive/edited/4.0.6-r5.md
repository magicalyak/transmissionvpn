## Original release body

## 🏷️ Versioning Alignment & Documentation Fixes

This release establishes proper versioning alignment with upstream LinuxServer.io transmission releases and resolves documentation inconsistencies.

### 🔧 Major Changes

- **🏷️ Versioning Alignment**: Adopted `4.0.6-rX` format to match [LinuxServer.io transmission releases](https://github.com/linuxserver/docker-transmission/releases)
- **🧹 Tag Cleanup**: Removed problematic version tags (v25.0.x series, v4.0.7+) that exceeded upstream versions
- **📚 Documentation**: Added comprehensive versioning scheme documentation to README
- **🔧 Environment Variables**: Fixed `TRANSMISSION_WEB_UI` → `TRANSMISSION_WEB_UI_AUTO` in advanced configuration table

### 🏷️ New Versioning Scheme

**Format**: `4.0.6-rX`
- **`4.0.6`** - Matches upstream Transmission version from LinuxServer.io  
- **`-rX`** - Our revision number (increments with each release)

**Examples**:
- `4.0.6-r1` - First release based on Transmission 4.0.6
- `4.0.6-r2` - Second release with bug fixes/features  
- `4.0.6-r5` - **Current release** (this version)

### 📋 Environment Variable Fixes

For users updating wrapper scripts, ensure you're using:

- ✅ `TRANSMISSION_WEB_UI_AUTO` (not `TRANSMISSION_WEB_AUTO`)
- ✅ `ENABLE_PRIVOXY` (not `WEBPROXY_ENABLED`)
- ✅ `CHECK_DNS_LEAK` (not `CHECK_DNS_LEAKS`)  
- ✅ `CHECK_IP_LEAK` (not `CHECK_IP_LEAKS`)

### 🎯 Why This Change?

1. **Upstream Compatibility**: Ensures our versions don't exceed the base LinuxServer.io image
2. **Clear Tracking**: Makes it obvious which upstream version we're based on
3. **Proper Semantics**: Revision numbers for our enhancements, major.minor for upstream updates
4. **User Clarity**: Eliminates confusion about version relationships

### 🔄 Migration Notes

- **Docker Images**: Use `magicalyak/transmissionvpn:4.0.6-r5` or `magicalyak/transmissionvpn:latest`
- **Previous Users**: No functional changes - this is purely versioning and documentation
- **Wrapper Scripts**: Update environment variable names as listed above

### 🚀 Going Forward

- **Revision Updates** (`4.0.6-r6`, `4.0.6-r7`, etc.): Bug fixes, features, documentation
- **Version Updates** (`4.1.0-r1`): When LinuxServer.io updates Transmission

This establishes a sustainable versioning strategy aligned with our upstream dependencies.
